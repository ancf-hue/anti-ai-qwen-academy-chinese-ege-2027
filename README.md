# анти-ии квен академия китайский язык егэ-2027

Бесплатный социальный офлайн-проект — тренажёр ЕГЭ-2027 по китайскому языку по официальной демоверсии, спецификации и кодификатору ФИПИ.

> 🌐 **Онлайн-версия:** [ancf-hue.github.io/anti-ai-qwen-academy-chinese-ege-2027](https://ancf-hue.github.io/anti-ai-qwen-academy-chinese-ege-2027/)

## 📌 О проекте

Тренажёр работает в любом браузере без установки, без интернета и без регистрации. Все ответы проверяются локально — ваши данные никуда не отправляются. Поддерживается двуязычный интерфейс (RU / EN).

### Что внутри

- **32 задания**: 29 письменных (аудирование, чтение, грамматика/лексика/иероглифика, письмо) + 3 устных
- **80 первичных баллов**
- **180 минут** на выполнение
- Встроенный таймер экзамена с пресетами (180 / 60 / 30 минут)
- Чек-лист подготовки и подробный план на 25 дней
- Автопроверка для заданий с кратким ответом и приближённая самооценка по критериям ФИПИ для развёрнутых ответов (письмо и устная часть)

## 📚 Структура тренажёра

| Раздел | Задания | Первичные баллы |
|---|---|---|
| **Аудирование** | 1–9 | 14 |
| **Чтение** | 10–14 | 13 |
| **Грамматика и лексика** | 15–27 | 13 |
| **Письменная речь** | 28–29 | 20 |
| **Устная часть** | 30–32 | 20 |
| **Итого** | **32** | **80** |

## 🎧 Аудиофайлы

Для полноценной работы раздела «Аудирование» положите рядом с файлом `index.html` аудиофайл:
- `audio.mp3` — запись для заданий 1–9 (демоверсия ФИПИ).
